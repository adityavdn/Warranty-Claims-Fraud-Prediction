# 🔍 Warranty Claims Fraud Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![ML](https://img.shields.io/badge/ML-Fraud_Detection-red.svg)

## 📖 Overview

Machine learning model to detect fraudulent warranty claims using classification algorithms. Analyzes claim patterns, customer behavior, and product data to identify potentially fraudulent activities.

## 🎯 Features

- Binary classification (Fraud/Legitimate)
- Feature engineering from claim data
- Imbalanced dataset handling (SMOTE)
- Model evaluation with precision/recall focus

## 🛠️ Tech Stack

- Scikit-learn, XGBoost, LightGBM
- Pandas, NumPy
- Imbalanced-learn (SMOTE)

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Warranty-Claims-Fraud-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Performance

- Accuracy: 94%+
- Precision: Focus on minimizing false positives
- Recall: Maximizing fraud detection
